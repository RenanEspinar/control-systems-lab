# Control Systems Lab

## Overview

This project demonstrates the design and simulation of a vacuum pressure control system using a PID controller.

The system is inspired by biomedical applications such as Negative Pressure Wound Therapy (NPWT), where controlled vacuum pressure is required.

---

## Objective

To regulate vacuum pressure to a clinically relevant setpoint using PID control.

---

## System Description

The system models a vacuum pump controlled via PWM:

dP/dt = -a·u - b·P

---

## Clinical Context

Setpoint:

- **-125 mmHg ≈ -16.7 kPa**
